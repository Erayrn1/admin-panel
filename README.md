# Admin Panel

Modern, kullanışlı ve responsive bir admin paneli uygulaması.

## Özellikler

- ✅ Dashboard (istatistikler, grafikler)
- ✅ Kullanıcı yönetimi
- ✅ Rol ve izin sistemi
- ✅ İçerik/Ürün yönetimi
- ✅ Ayarlar yönetimi
- ✅ Responsive tasarım
- ✅ Dark/Light mod
- ✅ Gerçek zamanlı veriler

## Tech Stack

**Backend:**
- Node.js + Express
- MongoDB
- JWT Authentication
- Mongoose ODM

**Frontend:**
- React 18
- Tailwind CSS
- React Router v6
- Chart.js (grafikler)
- Axios

## Kurulum

### Backend Kurulumu

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend Kurulumu

```bash
cd frontend
npm install
npm start
```
